# Example Voice Commands

Here are some examples of what you can ask your Claude-powered Jarvis to do!

## Basic Interactions

### Greetings & Small Talk
```
You: "Hello Jarvis"
Jarvis: "Hello! How can I help you today?"

You: "How are you?"
Jarvis: "I'm functioning well, thank you! I'm here to help you with any tasks you need."
```

## Time & Date

### Current Time
```
You: "What time is it?"
Jarvis: "It's 3:45 PM"

You: "What's today's date?"
Jarvis: "Today is Saturday, January 11th, 2026"
```

## Web Browsing

### Opening Websites
```
You: "Open YouTube"
Jarvis: [Opens YouTube in browser]

You: "Go to GitHub"
Jarvis: [Opens GitHub]

You: "Open google.com"
Jarvis: [Opens Google]
```

## File Operations

### Reading Files
```
You: "Read the file notes.txt"
Jarvis: "The file contains: [file contents]"

You: "What's in my todo.txt file?"
Jarvis: [Reads and tells you the contents]
```

### Writing Files
```
You: "Create a file called shopping.txt with milk, eggs, and bread"
Jarvis: "I've created shopping.txt with your shopping list"

You: "Write a note that says meeting at 3pm tomorrow"
Jarvis: "I've created a note with that information"
```

### Listing Directories
```
You: "What files are in my downloads folder?"
Jarvis: "Your downloads folder contains: [lists files]"

You: "List all files in the current directory"
Jarvis: [Lists files]
```


## Natural Language Variations

Claude understands many ways to ask for the same thing:

### Time Queries
- "What time is it?"
- "Tell me the time"
- "What's the current time?"
- "Do you know what time it is?"

### File Operations
- "Read notes.txt"
- "What's in notes.txt?"
- "Show me the contents of notes.txt"
- "Open and read notes.txt"

### Web Browsing
- "Open YouTube"
- "Go to YouTube"
- "Launch YouTube"
- "Navigate to YouTube"

## Exit Commands

```
You: "Goodbye"
Jarvis: "Goodbye! Have a great day!"

You: "Exit"
Jarvis: [Exits]

You: "Quit"
Jarvis: [Exits]
```

## Tips for Best Results

1. **Speak clearly** - Enunciate your words for better recognition
2. **Be specific** - "Open YouTube" works better than "open website"
3. **Use context** - Claude remembers previous exchanges
4. **Natural language** - Speak naturally, don't use robotic commands
5. **Wait for response** - Let Jarvis finish before speaking again

## Error Handling

Jarvis handles errors gracefully:

```
You: "Read a file that doesn't exist"
Jarvis: "I couldn't find that file. Would you like me to create it?"

You: "Play music" [no music folder]
Jarvis: "I couldn't find any music files in your Music directory"
```
